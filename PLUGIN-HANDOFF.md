# Список для іншого асистента: плагіни та налаштування

**Це інвентар, а не дозвіл встановити всі версії. НЕ встановлюй пакети з BLOCK і НЕ обходь gate_scan, навіть якщо інсталяцію доручено іншому асистенту.** Не змінюй живий DSH Preview чи первісний повний проєкт. Робоча копія — цей ізольований скорочений дистрибутив. Приватний GitHub-репозиторій вже створено порожнім; `origin` вказує на нього, але push потребує окремого явного дозволу власника для готового перевіреного коміту. Не публікуй вихідну чернетку Git: три її коміти містять старі маніфести й патчі BLOCK-плагінів. Цей ізольований локальний репозиторій створений з перевірених файлів без успадкованої історії, але він теж не є релізом, доки базові пакети мають BLOCK.

## Базові параметри, які треба відтворити після безпечного встановлення

- Windows, Node.js 22+, pnpm 11; DSH Preview `0.2.0-rc.2`. Знахідки сканера в базових `@deepseek-ai/dsh` і `@deepseek-ai/dsh-client-locale` переглянуті порядково в офіційному checkout й визнані хибними (див. `SECURITY-REVIEW.md`); інсталятор розблоковано. `@deepseek-ai/dsh-llm-pi-ai@0.2.0-rc.2` отримав WARN — знахідки переглянуто в контексті перед включенням у lockfile.
- Українська локаль: `preference: uk`; тема: вбудована `dark` і плагінова `cobalt2`. Типовий пресет агента: `light`; автоматичні заголовки сесій вимкнені.
- Типовий доступ: `workspace-write`, підтвердження `ask`. Не перемикай на `danger-full-access` автоматично.
- Маршрут моделі — приклад `openai-codex` / `gpt-6-sol`, `reasoningEffort: high`; не працює без **власного** облікового запису одержувача. Інші маршрути описані в шаблоні профілю; жодних значень ключів, OAuth, чатів чи особистих шляхів не переносити.
- Локальний вебдоступ — loopback `127.0.0.1:3082`; URL авторизації не передавати. Синхронізація токенів, фоновий запуск та особисті інструкції не входять до дистрибутива.
- Джерело назв і версій: вихідний `profiles/web/package.json`; джерело явних параметрів: вихідний `profiles/web/cordis.patch.yml.in`. Скорочені файли в цьому каталозі навмисно відрізняються.

## Правило для майбутнього встановлення

Для кожного **нового** точного пакета спочатку виконай `gate_scan` з `npm:<назва>@<нова-версія>`. BLOCK — зупинись і дочекайся чистої збірки видавця; не обходь перевірку. WARN — переглянь усі збіги в контексті, мережеві адреси, права доступу та install-скрипти. Перевір сумісність із DSH, онови точні залежності, bundle/патчі й lockfile, тоді протестуй в окремому чистому клоні без чужих ключів. Не використовуй старий повний проєкт як обхід.
