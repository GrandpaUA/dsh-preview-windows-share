Both `install.ps1` and `Start-Harness.ps1` intentionally fail closed. An existing local Preview instance does not establish that a fresh install is permitted. **No clean installation or new browser test has been performed for this candidate.**

This isolated copy is derived from the original full-set draft without modifying it. Its web profile retains exactly these non-first-party dependencies: `@dshthemes/ui@0.2.0` (WARN, five medium hits attributed to dictionary/documentation), `dock-base@0.2.4` (PASS), and four local plugins: `dsh-codex-failover`, `dsh-locale-uk`, `dsh-wide-chat`, `dsh-headroom`. The executable local-source scans returned PASS for codex-failover and wide-chat; locale WARN is caused by literal translation data, not executable network calls; headroom WARN is a Unicode character-range regex. The locale registers dictionaries and transforms localized text; headroom stores exact retrieved output in memory but its `ccr.persist: false` profile setting disables saving that text to its usual plaintext store. Codex failover can read and replace the active credential when a separately configured second account is available and quota is exhausted; no credential value is included in Git. These static results are heuristic, not warranties. First-party runtime and its transitive dependency tree still require their own clearance and installation checks.

In addition to the six blocked pins below, this reduced profile omits the original quota widget, slash-command extension, dock file browser/Git panel, checkpoint diff/rewind, classic coding editor, auto-continue, and context dashboard. Reasons include token access and provider requests, broad workspace/file modification, direct write to arbitrary absolute paths, background model turns, and plaintext checkpoint copies. The reduced profile is **not feature-equivalent** to the current Preview installation. `dock-base` remains as an inert dock shell; the file browser and browser editors are absent. First-party DSH features can still exist but have not been runtime-verified here.

## Intended future use (not executable while the safety hold remains)

Requires Windows 10/11 x64, Node.js 22+, pnpm 11, Git and registry access. After *all* gates clear, clone the intended repository and run `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`; it installs and starts DSH on loopback port 3082. Use `-NoStart` only when installing without launching; use `Start-Harness.ps1` for later restarts. The installer validates the Git release, creates a local ignored profile from the template and installs both exact frozen lockfiles. It preserves an existing ignored profile instead of overwriting it. No daemon, autostart or accounts are bundled. The default provider is a nonworking `openai-codex` example until the recipient adds their own credentials; do not place credentials in Git. The default agent permission is `workspace-write` with confirmation, not the source machine's broader preset. Browser/CLI authorization URLs and logs may contain tokens; do not share them.

This Git candidate intentionally excludes API keys, OAuth state, chats, attachments, workspaces, backup files, authorization tokens, private instruction files and scheduled tasks. The Git allowlist in `.gitignore` is not a security boundary. **Do not push the original draft or its existing Git history:** its three commits retain the old blocked-plugin manifests and patches even after their removal from the current files. Use a fresh repository from the reviewed allowlisted files only, with no inherited `.git` history; inspect its new commit and remote before any authorized push. A fresh local staging repository is still NOT RELEASED while the package gates remain blocked. The release verifier checks tracked and untracked **nonignored** files for known secret/state patterns, but cannot prove absence of all private information. See [the local security review](SECURITY-REVIEW.md) for the staged-file audit, limitations and simplest future installation path. Local patches/lockfiles are pinned; Node.js, npm tarballs and an offline cache are not bundled. Review upstream licenses before redistribution. The local headroom plugin includes Apache-2.0 LICENSE and NOTICE; the light bootstrap credits its MIT inspiration.
