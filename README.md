## Встановлення

Requires Windows 10/11 x64, Node.js 22+, pnpm 11, Git and registry access. Clone the repository and run `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`; it verifies the release files, creates a local ignored profile from the template, installs both exact frozen lockfiles and starts DSH on loopback port 3082. Use `-NoStart` to install without launching; use `Start-Harness.ps1` for later restarts. The installer preserves an existing ignored profile instead of overwriting it. No daemon, autostart or accounts are bundled. The default provider is a nonworking `openai-codex` example until the recipient adds their own credentials; do not place credentials in Git. The default agent permission is `workspace-write` with confirmation, not the source machine's broader preset. Browser/CLI authorization URLs and logs may contain tokens; do not share them. Full step-by-step instructions for the client: [INSTALL-PLAN.md](INSTALL-PLAN.md). Optional Windows Task Scheduler setup after package clearance and a successful manual start: [AUTOSTART.md](AUTOSTART.md). Practical lessons from several adjacent Harness sessions, checked against this smaller profile: [OPERATING.md](OPERATING.md).

This Git candidate intentionally excludes API keys, OAuth state, chats, attachments, workspaces, backup files, authorization tokens, private instruction files and scheduled tasks. The Git allowlist in `.gitignore` is not a security boundary. **Do not push the original draft or its existing Git history:** its three commits retain the old blocked-plugin manifests and patches even after their removal from the current files. Use a fresh repository from the reviewed allowlisted files only, with no inherited `.git` history; inspect its new commit and remote before any authorized push. The release verifier checks tracked and untracked **nonignored** files for known secret/state patterns, but cannot prove absence of all private information. See [the local security review](SECURITY-REVIEW.md) for the staged-file audit, limitations and simplest future installation path. Local patches/lockfiles are pinned; Node.js, npm tarballs and an offline cache are not bundled. Review upstream licenses before redistribution. The local headroom plugin includes Apache-2.0 LICENSE and NOTICE; the light bootstrap credits its MIT inspiration.
